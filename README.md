# THREADLENS — Traffic Essence

스레드(Threads) 트래픽 분석 도구의 웹 배포판입니다.

- 결과값(반응) 데이터는 접속한 기기의 브라우저에만 저장됩니다. 서버로 전송되지 않습니다.
- 새 기기에서 열면 [결과값 수집·관리]에서 JSON 파일을 가져와야 이전 분석이 보입니다.

## 업종별 글 만들기 (`new/`)

소상공인·자영업자용 스레드 글 구조 모음입니다. 업종과 소재를 넣으면 72가지 구조 중 맞는 것을 골라 프롬프트를 만들고 ChatGPT로 넘깁니다.

- 업종·글 구조 고치기: `new/assets/data.js`
- 사이트 안에서 바로 글 받기(선택): `new/server/설치안내.md`
