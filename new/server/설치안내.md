# 사이트 안에서 글이 바로 나오게 하는 방법

지금 스레드렌즈는 프롬프트를 만들어 제미나이로 넘깁니다.
아래 세 가지를 하면 "글 만들기"를 누르는 즉시 사이트 안에서 글이 나옵니다.

메뉴 이름은 각 서비스가 바꿀 수 있어서, 화면과 다르면 비슷한 이름을 찾으세요.

## 드는 돈

- 글은 Claude(Opus 5.5)가 씁니다. 글 한 개에 대략 30~50원이 듭니다. (입력 100만 토큰당 4달러, 출력 20달러 기준의 어림값입니다.)
- 하루 300개 한도를 다 쓰면 하루 1만~1만 5천 원쯤입니다. 한도는 아래 3번에서 바꿀 수 있습니다.
- 더 싼 모델로 바꾸면 수십 분의 1로 줄어듭니다. `worker.js` 맨 위 `MODEL` 한 줄만 바꾸면 됩니다.
- Cloudflare는 하루 10만 번 요청까지 무료입니다.

## 1. Anthropic API 키 만들기

1. console.anthropic.com 에 가입하고 결제 수단을 등록합니다.
2. API Keys 메뉴에서 키를 새로 만들고 복사해 둡니다. 이 키는 다른 사람에게 보여주면 안 됩니다. 깃허브에도 올리지 않습니다.
3. 같은 곳에서 월 사용 한도(Spend limit)를 정해 두면 안심입니다.

## 2. Cloudflare에 서버 올리기

1. cloudflare.com 에 가입합니다.
2. Workers 메뉴에서 새 Worker를 만듭니다. 이름은 `threadlens` 로 합니다.
3. 코드 편집 화면에서 원래 있던 내용을 지우고, 이 폴더의 `worker.js` 내용을 전부 붙여넣은 뒤 배포합니다.
4. 배포하면 `https://threadlens.○○○.workers.dev` 같은 주소가 생깁니다. 이 주소를 적어 둡니다.

## 3. 설정값 넣기

Worker 설정의 "변수 및 비밀"에서 아래를 넣습니다.

| 이름 | 종류 | 값 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 비밀 | 1번에서 복사한 키 |
| `ALLOWED_ORIGIN` | 일반 | 스레드렌즈 사이트 주소 (예: `https://www.example.com`) |
| `DAILY_MAX` | 일반 | 하루 전체 한도. 안 넣으면 300 |
| `PER_IP_MAX` | 일반 | 한 사람당 하루 한도. 안 넣으면 20 |

한도가 실제로 작동하려면 KV 저장소가 필요합니다.

1. Cloudflare의 KV 메뉴에서 저장소를 하나 만듭니다. 이름은 아무거나 됩니다.
2. Worker 설정의 "바인딩"에서 그 KV를 **`LIMITS`** 라는 이름으로 연결합니다.

KV를 연결하지 않으면 한도 없이 누구나 무제한으로 쓸 수 있어 요금이 크게 나올 수 있습니다. 꼭 연결하세요.

## 4. 사이트에 주소 적기

`threadlens/assets/config.js` 의 따옴표 안에 2번에서 적어 둔 주소를 넣습니다.

```js
var TL_API = 'https://threadlens.○○○.workers.dev';
```

저장해서 깃허브에 올리면 끝입니다. 주소를 다시 비우면 예전처럼 제미나이로 넘깁니다.

## 알아둘 점

- 이 서버 코드는 가짜 응답으로만 시험했습니다. 실제 키를 넣은 뒤 글이 잘 나오는지 한 번 확인해야 합니다.
- 서버는 스레드렌즈가 만든 프롬프트만 받습니다. 다른 사이트에서 보낸 요청과 형식이 다른 요청은 거절합니다.
- 회원 가입과 고객 정보 저장은 아직 없습니다.
